# Wireframe Write-up - Color Collection

My website is a small color collection with two pages: a landing page (Home) and a Gallery page. I designed it mobile-first, which means I started with the smallest screen and expanded the layout for larger screens.

The landing page has a different layout from the rest of the site because it needs to introduce the site and attract visitors. On mobile, it has a header with a menu button, a large hero image, a heading, a call-to-action button, and three content cards stacked vertically. On large screens, the navigation expands into links, the hero image stretches wider, and the three cards sit in a single row.

The Gallery page focuses on images. On mobile, the figures stack in one column with a 10px gap. From 772px, the layout switches to two columns and the last figure spans both columns. From 992px, every third figure spans both columns to create visual rhythm.

The wireframes intentionally use no colors or fonts. Boxes with an X are image placeholders and gray bars are text placeholders. This lets me focus on layout and the order of information before choosing a visual style.
